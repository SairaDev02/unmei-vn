# Triage labels

Agent skills name five triage roles. This page maps each role to the label string this repository uses. [CONTRIBUTING.md § How to report an issue](../../CONTRIBUTING.md#how-to-report-an-issue) owns what each label means.

| Role a skill names | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information from the reporter | `needs-info` |
| Ready for an agent working alone | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not be actioned | `wontfix` |

`ready-for-agent` and `ready-for-human` both mean the issue is accepted.
