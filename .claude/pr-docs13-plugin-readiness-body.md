Main findings:

- **UI plugin:** the furthest from ready. Every surface builds its tree in Rust (about 6,900 lines), and variant E and the Backlog are not built.
- **Check and preview:** close. The launch parser and the CI screenshot capture are ready to build on. `load_pack` stops early on some errors, and `LoadError` has no rule id.
- **Stage plugin and language packs:** both change saved games. Stage needs sprite positions; language packs need the line before `{var}` is filled in, because the runner fills it before saving. The doc suggests planning both changes together.
- **Authoring profile:** small. It fits into the existing CLI prompt and validation gate.

Suggested spec order: check and preview, then the authoring profile, the UI plugin with variant E, the stage plugin, UI sounds and speaker style, and language packs last.

**Acceptance criteria:** none set in advance. This audit was asked for before the spec phase.
